
# 🐍 Python Student Information System

## 📌 Project Overview

This is my Day 1 Python project created as part of my Python Developer Journey.

The program takes student information from the user and displays it in a clean and formatted way.

---

## 🎯 Features

- Take student name
- Take student age
- Take college name
- Take course name
- Take city name
- Take state name 
- Display all information in a formatted output

---

## 🛠️ Technologies Used

- Python 3
